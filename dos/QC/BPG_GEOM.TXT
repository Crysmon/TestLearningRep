 зубчатых передач при комбинировании норм точности (общий случай):
             N-N-N-NN/N-N
             │ │ │ ││ │ └─ Гарантированный боковой зазор, мкм
             │ │ │ ││ └─── Класс отклонений монтажного размера
             │ │ │ │└───── Вид сопряжения
             │ │ │ └────── Вид допуска на боковой зазор
             │ │ └──────── По нормам контакта зубьев
             │ └────────── По нормам плавности работы
             └──────────── По нормам кинематической точности
 При соответствии  вида  допуска на боковой зазор виду сопряжения
 допускается не указывать вид допуска на боковой зазор. Пользова-
 тетель имеет возможность задать каждый из параметров, входящих в
 степень точности передачи по подсказке, нажав клавишу F4        \
