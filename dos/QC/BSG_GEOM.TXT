@Ввод в окне "Данные"
    Окно "Данные"  предназначено для ввода основных параметров передачи необ-
 ходимых для выполнения расчета. Расчет можно вести либо по среднему нормаль-
 ному,  либо по внешнему окружному модулю. Для смены модуля необходимо, нажав
 клавишу F4, перейти в окно выбора модуля и переставить клавишей Enter указа-
 тель √ на нужный тип модуля. Номинальные значения модуля рекомендуется выби-
 рать по ГОСТ 9563-60.  Если заданы габаритные размеры передачи,  внешнее ко-
 нусное расстояние или внешний делительный диаметр диаметр шестерни или коле-
 са,  то в окне выбора модуля можно получить его  расчетное  значение,  задав
 требуемый габаритный размер и нажав клавишу Enter.
    При задании коэффициента смещения,  коэффициента изменения толщины зуба и
 ширины зубчатого венца по клавише F4 можно получить рекомендуемое значение.
    Для базового расстояния и диаметра среза F4 даст предельные значения. Ба-
 зовые расстояния и диаметр среза можно не задавать.
    При задании диаметра инструмента по клавише F4 появляется окно  стандарт-
 ных диаметров.  Рекомендуемые диаметры выделены цветом.  Диаметр инструмента
 можно задавать в дюймах (например 3.5").При  вводе  направления  линии  зуба
 "Левое"  на "Правое" меняется по клавише Enter или F4.  Углы задаются либо в
 градусах,  минутах,  секундах и 1/60 секунды (значения градусов, минут и се-
 кунд разделяются запятыми) либо в десятичной форме.  Например 34 град 16 мин
 34 сек записываются 34,16,34 или 34.27611.                                  \

@Задание степени точности
    Степень точности  задается  в  соответствии с ГОСТ 1758-81 для
 зубчатых передач при комбинировании норм точности (общий случай):
        N-N-N-Mm
        │ │ │ │└───── Вид допуска на боковой зазор (a,b,c,d,h)
        │ │ │ └────── Вид сопряжения (A,B,C,D,E,H)
        │ │ └──────── По нормам контакта зубьев (4...12)
        │ └────────── По нормам плавности работы (4...12)
        └──────────── По нормам кинематической точности (4...12)
    При соответствии вида допуска на боковой зазор виду сопряжения
 допускается не указывать вид допуска на боковой зазор.  Пользова-
 тетель имеет возможность задать каждый из параметров,  входящих в
 степень точности передачи по подсказке, нажав клавишу F4.        \

@Методика расчета
    Программа выполняет геометрический расчет конических ко-
 лес с круговыми зубьями внешнего зацепления. Межосевой угол
 от 10 до 150 град. Угол наклона зуба от 0 до 45 град.   Ис-
 ходный контур с прямолинейным профилем по ГОСТ 16202-81 или
 нестандартный.
    Расчет ведется по методике стандарта ГОСТ 19326-73.  Все
 термины,  определения  и  буквенные   обозначения  понятий,
 соответствуют  ГОСТ 16530-83 и ГОСТ 16531-83.   Номинальные
 значения модуля выбираются по ГОСТ 9563-60.  Выбор допусков
 ведется по заданным нормам точности -  ГОСТ 1758-81 и  OCT2
 Н36-2-78. Программа рассчитывает таблицы  параметров зубча-
 того венца   колес передачи для выполнения рабочих чертежей
 в соответствии с ЕСКД (ГОСТ 2.403-75).                     \
