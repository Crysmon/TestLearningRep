@"Передача"
    Окно  "Передача"  предназначено  для  ввода  основных параметров передачи
 необходимых  для  выполнения  расчета.
    При задании коэффициента смещения, ширины зубчатого венца  по  клавише F4
можно получить рекомендуемое значение.
    Углы задаются либо в градусах, минутах, секундах и 1/60 секунды (значения
 градусов, минут и секунд разделяются запятыми) либо в градусах одним числом.
 Например 34 град 16 мин  34 сек записываются 34,16,34 или 34.27611.
    Степень точности  задается  в  соответствии с ГОСТ 1758-81 :
        N-N-N-Mm
        │ │ │ │└───── Вид допуска на боковой зазор (a,b,c,d,h)
        │ │ │ └────── Вид сопряжения (A,B,C,D,E,H)
        │ │ └──────── По нормам контакта зубьев (4...12)
        │ └────────── По нормам плавности работы (4...12)
        └──────────── По нормам кинематической точности (4...12)
