@Проектный расчет
    Для  проектного  расчета пружины  необходимо задать материал,рабочий
 угол,крутящий момент(предварительный).
 Зазор автоматически принимается равным  0.5 мм,длина одного зацепа рав-
 ным 0.0 мм,коэффициент запаса - 2.
 Отношение крутящего момента предварительного к рабочему - 0.4,отношение
 крутящего момента maксимального к рабочему  -  1.25,индекс пружины - 8.
 Если Вы не согласны с данным выбором, то зазор, длину зацепа, коэффици-
 ент запаса можно задать в исходных данных, а отношение  крутящего моме-
 нта предварительного к рабочему,крутящего момента  maксимального  к ра-
 бочему,индекс пружины в проектном расчете головного меню.
 Проектный расчет можно провести с помощью функциональной клавиши  F5  в
 исходных данных или из головного меню.
 Диаметр проволоки подбирается ближайшим рекомендуемым для данного мате-
 риала.
    Если  пружина не удовлетворяет  критерию расчета в окно  результатов
 на последней строке вписывается сообщение об этом.                      \
?  Нажмите любую клавишу

@Проверочный расчет
    Для проверочного расчета пружины необходимо задать материал,рабочий
 угол,крутящий момент(предварительный),крутящий  момент(рабочий), число
 витков,диаметр проволоки,диаметр средний.
 Число исходных данных является избыточным.На параметре являющимся рас-
 четным поставьте с помощью клавиши F8 символ √ и не заполняйте его.
 В проверочном  расчете материал проволоки не может быть помечен симво-
 лом √.
 Зазор автоматически принимается равным 0.5 мм,длина одного зацепа рав-
 ным 0.0 мм,коэффициент запаса - 2.
 Если  Вы не согласны с данным выбором, то зазор,длину зацепа,коэффици-
 ент запаса можно задать в исходных данных
 Отношение крутящего момента maксимального к рабочему - 1.00.
    Проверочный  расчет можно провести с помощью функциональной клавиши
 F6 в исходных данных или из головного меню.
    Если  пружина не удовлетворяет  критерию расчета в окно результатов
 на последней строке вписывается сообщение об этом.                      \
?  Нажмите любую клавишу

@Расчет пределов
  Расчет производится по формуле:
          3   Kк * Мраб.            4*q-1       Dо
       dпр =───────────── ,где  Kк=─────── , q=─────
              0.1 * [G]             4*q-4       dпр

  Для расчета минимального предела прочности подведите маркер на мате-
  риал проволоки предварительно задав:рабочий крутящий момент,диаметр
  проволоки,средний диаметр пружины,козффициент запаса.
  Для расчета максиммального рабочего крутящего момента на эту позицию
  предварительно задав:материал,диаметр проволоки,средний диаметр пру-
  жины,козффициент запаса.
  Для расчета  минимального диаметра проволоки подведите маркер на эту
  позицию  предварительно задав:материал,рабочий крутящий момент,сред-
  ний диаметр пружины,козффициент запаса.
  Расчет пределов можно  провести с  помощью функциональной клавиши F7 в
  исходных данных или из головного меню.                                 \
?  Нажмите любую клавишу

@Установка параметра-результата
   Набор параметров в окне исходных данных является
 избыточным. Один из параметров можно не задавать и
 он будет расчитываться программой. Для выбора этого
 параметра установите на него маркер окна и нажмите
 клавишу F8 или используйте вариант "Уст.рез." в го-
 ловном меню. Параметр-результат отмечается в окне
 данных символом "√". Маркер на эту позицию не уста-
 навливается.                                       \
