@Общая структура программы
   Программа для своей работы использует набор окон, одно из которых
постоянно находится в активном состоянии. С помощью клавиш перемещения
курсора в пределах окна может перемещаться маркер окна, выделенный
цветом.Для каждого окна на последней строке написаны возможные варианты
нажатий клавиш в этом окне.
   Для выбора варианта меню всегда используется клавиша "Enter".
   Для выхода из меню без выбора всегда используется клавиша "Esc".
   После запуска программы экран заполнен тремя окнами:
     -окно данных
     -окно банка шпонок
     -окно длин шпонок
Переход из окна данных в банк шпонок присходит по клавише F4 из позиций
'Ширина шпонки','Высота шпонки','Глубина паза вала'.
   В банке шпонок и других окнах выбор и запись в набор данных происхо-
дит  при нажатии клавиши 'Enter'. При нажатии клавишы 'Esc'  выход  из
из окна осуществляется без записи данных.
Выбор и расчет шпонки запускается либо из головного меню, либо из окна
данных по клавишам F5 и F6.
   Выход из программы возможен при выборе варианта "Конец" из головного
меню.                                                                   \
?  Нажмите любую клавишу

@Как пользоваться программой
    Самый короткий путь для получения бланка  расчета  шпоночного
соединения  состоит из следующих действий:
   1. Находясь в окне ввода данных (после запуска программы),введите
требуемые данные. Если Вы затрудняетесь ввести какое-либо значение,то
нажмите в этой позиции клавишу F4.
   2. Если вы хотите подобрать шпонку, задайте крутящий момент и диа-
метр вала и нажмите клавишу F5. Программа по заданному диаметру выбе-
рет  размеры сечения и по условию прочности на смятие и срез подберет
длину шпонки.
   3. Если  вы хотите  проверить существующую шпонку, задайте необхо-
димые исходные данные и нажмите клавишу F6.
   4. Нажатием клавиши F10 перейдите в головное меню и выберите
вариант "Печать". В меню печати выберите устройство,на котором Вы
хотите получить бланк расчета.                                       \
?  Нажмите любую клавишу

@Методика расчета
   Расчет шпоночного соединения производится на смятие и шпонки на
срез. Размеры сечения шпонки выбираются по диаметру вала в соотве-
тствии  с ГОСТ 23360-78 или ГОСТ 10748-79. Длина шпонки выбирается
из стандартного ряда из условия прочности на смятие и срез.
  Литература: Решетов Д.Н. Детали машин. М.,Машиностроение, 1979.   \
