@Выбор инструмента в окне "Инструмент"
  При нажатии клавиши "Enter" можно задать инструмент для нарезания колес. По
умолчанию оба колеса нарезаются прочим инструментом ( не долбяком), например
шестерня - инструментальной рейкой, а колесо с внутренними зубьями - червячной
фрезой; при этом параметры инструмента определяются исходным контуром.
  При нажатии клавиши "Enter" в позиции "Долбяк" происходит переход в одно из
двух окон "Долбяк". При нажатии в нем клавиши "Enter" в позиции "Выбор долбяка
из банка" происходит переход в банк чистовых зуборезных долбяков,где активизи-
рованы клавиши:
  Enter - выбор текущего долбяка и заполнение 1-6 позиций окна "Долбяк";
  F1 - обозначения параметров долбяков;
  F8 - поиск рекомендуемых долбяков;
  F9 - фильтр (после предварительного поиска);
    Клавиши редактирования используются только в неотфильтрованном банке.
  При нажатии клавиши "Enter" в позиции "Выбор коэф. смещения долбяка" пользо-
ватель (если предварительно выбран долбяк ) попадает в сооответствующее окно,
где можно выбрать x0 для нового, полностью сточенного, с min возможным углом
станочного зацепления с обрабатываемым колесом или долбяка с промежуточной пе-
реточкой (по клавише "Enter"). Клавиши:
  F4-подсказка по диапазону x0 долбяка; F5-расчет промежуточных переточек;
  В позициях "Модификация профиля" и "Класс точности" возможен выбор модифици-
рованного/немодифицированного долбяка (при модификации исходного контура) и
класса точности зуборезного долбяка.                                         \

@Методика расчета геометрии зубчатой передачи с внешним зацеплением
    Расчет ведется по методике стандарта ГОСТ 16532-81, с учетом [1-2].
    Все термины, определения  и буквенные  обозначения понятий, соответствуют
ГОСТ 16530-83 и ГОСТ 16531-83.
    Номинальные значения модуля выбираются по ГОСТ 9563-60;
    Значения угла профиля и коэффициентов параметров зубьев исходного контура
зубьев выбираются по ГОСТ 9587-81 (мелкомодульные передачи с модулем от 0.1 до
не более 1.0 мм) и ГОСТ 13755-81 (передачи с модулем  от 1.0 до 40 мм).
    Параметры чистовых зуборезных долбяков, содержащиеся в банке долбяков, со-
ответствуют ГОСТ 10059-80 (мелкомодульные) и ГОСТ 9323-79 (крупномодульные).
    Выбор допусков ведется по заданным нормам точности - для мелкомодульных
зубчатых передач по ГОСТ 9178-81 и для крупномодульных - по ГОСТ 1643-81.
    Программа рассчитывает таблицы параметров зубчатого венца колес передачи
для выполнения рабочих чертежей в соответствии с ЕСКД (ГОСТ 2.403-75).
