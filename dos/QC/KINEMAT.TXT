@Общая структура программы
   После запуска программы экран заполнен 3-мя окнами:
     -окно "Кинематическая схема" условно отображает связи валов;
     -oкно "Связь" постоянно содержит полную информацию о передаче,
      на которой находится маркер окна "Кинематическая схема" и
      служит для редактирования этой информации;
     -окно "Вход и выход" служит для ввода информации о входном и
      выходном вале;
   Переход из окна "Кинематическая схема" в окно "Вход и выход" и
наоборот присходит по клавише Tab или через головное  меню выбором
одного из вариантов "Кинематическая схема" или "Входной и выходной
вал". В окно "Связь" вход только из окна "Кинематическая схема" по
клавише Enter. Выход из него по клавише Esc(без ввода) или F2
(с вводом связи).
   Головное  меню  вызывается клавишей F10 из окна "Кинематическая
схема" или "Вход и выход". В головном меню реализованы вызов расче-
тов и задание текущего вида расчета, печать результатов.Текущий вид
расчета можно вызывать непосредствено из окон нажатием клавиши F6.
   Выход  из  программы  происходит  при выборе варианта "Конец" из
головного меню или по клавише Alt-H(Halt) из любого места программы\
?3

@Ввод данных в окне "Кинематическая схема"
   Для ввода новой связи или редактирования уже введенной
установите маркер окна на требуемое место в схеме клавишами
"стрелка влево","стрелка вправо". Во время движения информация
в окне "Связь" будет постоянно обновляться. Выбрав связь
нажмите Enter и введите необходимые данные о передаче. Выход
из окна "Связь" по клавише F2.
   Для удаления связи без перемещения последующих связей
(очистка места) служит клавиша F8. Для вставки новой связи с
перемещением последующих вправо используется клавиша Alt-I
(Insert) для удаления с перемещением последующих вправо Alt-D
(Delete).                                                    \
?3

@Ввод данных в окне "Связь"
   Вход в окно "Связь" из окна "Кинематическая схема" по клавише Enter.
В позиции "Передача" нажмите Enter и выберите из меню вид передачи.
В позиции "Комментарий" можно вводить любую информацию. Вид передачи и
комментарий в расчете не используется.
   Для ввода передаточного отношения в зависимости от вида выбранной
передачи программа может предоставить либо позиции для ввода информации
о размерах ведущего и ведомого элементов, либо (для прочего вида)
позиции для ввода непосредственно прямого и обратного передаточного
отношения (например,ременная передача с большим скольжением).При выборе
муфты эти позиции недоступны для ввода. Под "передаточным отношением"
понимается отношение частоты вращения ведущего вала к частоте вращения
ведомого.Под "обратным передаточным отношением" понимается передаточное
отношение в ситуации, когда ведущим становится вал, заданный для этой
связи как ведомый.
   Состояние переключателей "Возможна/невозможна передача назад",
"Постоянно включена/Возможно отключение" и "Не изменяет/изменяет
направление вращения" устанавливается клавишей Enter.
   Для выхода из окна после ввода всех сведений используйте клавишу F2
или позицию "Ввод связи в схему". При этом программа проведет проверку
правильности введенной информации. Если Вы не хотите исправлять ошибки
выход возможен по клавише Esc. Но при этом вся введенная информация
будет потеряна.                                                       \
?3

@Ввод данных в окне "Вход и выход"
   Номера входного и выходного валов и частота вращения входного
вала вводятся непосредственно с клавиатуры.
   Исходную нагрузку можно задать различными способами. Для выбора
способа задания нагрузки нажмите в последней позиции окна клавишу
F4. Если двигатель уже выбран и во всех режимах будет использоваться
вся его мощность, выберите варианты "Момент на входном валу" или
"Мощность на входном валу". Если известна полезная нагрузка на
выходном валу, выберите вариант "Моменты на выходном валу". При
выборе этого варианта позиция ввода нагрузки в окне "Вход и выход"
становится нередактируемой, но нажатие клавиши Enter в этой позиции
приведет к расчету возможных режимов работы схемы и выводу полу-
ченной таблицы режимов с колонкой для ввода момента на выходном валу
для каждого режима. Выход из этой таблицы по клавише Esc. Контроль
правильности ввода в ней происходит при запуске расчета. Незаданный
для режима момент считается равным нулю.                           \
?3

@Виды расчетов
   Выберите в головном меню вариант "Расчет". Программа предоставит
меню видов расчета. При выборе какого-либо варианта клавишей Enter
производится расчет,а в меню выбранный вариант отмечается символом
"√" в качестве текущего. Текущий вид расчета можно вызывать непо-
средственно из окон основного экрана по клавише F6.
   Для видов расчета, где в качестве результата выводится график,
можно задать вид шкалы результатов: логарифмическая или равномерная
шкала. Переключение производится клавишей Enter.
   Для запуска расчетов "Циклограмма работы вала/передачи" необхо-
димо предварительно ввести с клавиатуры номер вала (1..9) или номер
передачи (A..T).                                                   \
?3

@Получение бланка расчета(печать)
   Выберите в головном меню вариант "Печать". Программа предоставит
меню элементов заполнения бланка. Задание или отмена какого-либо
элемента производится клавишей Enter и отмечается символом "√".
В позиции "Циклограмма работы вала/передачи" можно задать несколько
номеров валов и передач.
   Создание бланка расчета происходит при первом выборе устройства
вывода, где Вы хотите его получить:
   - на принтере
   - на диске  (в файл)
   - на экране (редактировать)
При повторном выборе устройства бланк только выводится, но не созда-
ется. Таким образом,например,бланк отредактированный на экране можно
напечатать на принтере.                                             \
