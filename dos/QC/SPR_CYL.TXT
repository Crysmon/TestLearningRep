@"Данные"
    Для проведения расчета необходимо заполнить данные(минимальные):
        - силу при предварительной деформации;
        - силу при рабочей деформации;
        - рабочий ход;
        - класс  пружины.
    Для проведения расчета с учетом конструктивных параметров можно
дополнительно задать:
        - максимальную скорость;
        - длину пружины при рабочей деформации (минимальную/максимальную);
        - диаметр пружины (минимальный/максимальный).                     \

@Выбор пружины
     Для предварительного выбора пружины необходимо расчитать все  пружины  в
банке.  Запуск  расчета  производится нажатием клавиши F5 в банке или из окна
данных,а также из окна "Расчет банка",вызываемого  из  головного  меню.  Если
пружина удовлетворяет всем установленным критериям, то она выделяется в банке
цветом. Если ни одна пружина не удовлетворяет критериям перейдите в окно дан-
ных  и  измените  их (облегчите условия работы пружины).Маркер установится на
первую отмеченную пружину.  Выберите любую из отмеченных пружин.  Если Вы  из
банка  перейдете в другое окно,то в качестве выбранной будет считаться пружи-
на,  на которой перед выходом стоял маркер банка. В банке будет отмечено цве-
том.
     Переход из  окна  данных в банк и обратно присходит по клавише "Tab" или
через головное меню (вызывается по F10) выбором  варианта  "Данные"/"Банк".По
клавише F9 (фильтр) можно собрать отмеченные пружины.                        \
?  Нажмите любую клавишу
@Расчет отдельной пружины
    Если пружина выбрана, ее можно рассчитать отдельно по критериям из ок-
 на данных или банка нажатием функциональных клавиш, а также из окна "Рас-
 чет пружины", вызываемого из головного меню.
    Если  пружина не удовлетворяет  критерию расчета в окно результатов на
 последней строке вписывается сообщение об этом.                          \
?  Нажмите любую клавишу
