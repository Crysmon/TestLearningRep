@Ввод данных для расчета цепи
   После запуска программы экран заполнен двумя окнами "Данные" и "Банк
цепей". Переход из окна данных в банк и обратно присходит по клавише "Tab"
или через головное меню выбором варианта "Данные" или "Банк".
   При вводе значений в некоторых позициях окна "Данные" по клавише F4
можно вызвать следующие вспомогательные окна:
   - При вводе частоты вращения предлагается таблица рекомендуемых частот.
   - При вводе числа зубьев ведущей звездочки предлагается окно для ввода
     передаточного отношения и при выходе из него по клавише Enter
     производится расчет рекомендуемого числа зубьев ведущей и ведомой
     звездочек.
   - При вводе числа зубьев ведомой звездочки,если уже задано число зубьев
     ведущей звездочки, также предлагается окно для ввода передаточного
     отношения и при выходе из него по клавише Enter производится расчет
     числа зубьев ведомой звездочки.
   - При вводе межосевого расстояния можно выбрать вариант задания
     собственно значения межосевого расстояния или задание его отношения к
     шагу цепи.
   - При вводе коэффициента угла наклона предоставляется окно для ввода
     угла наклона. Расчет коэффициента производится при  выходе по клавише
     Enter.
   - При вводе коэффициентов температуры,ударности и способа смазки
     предоставляется меню рекомендуемых значений.                        \
?3

@Выбор цепи
   Если цепь уже известна, то перейдите в банк и установите маркер на
выбранную цепь. В окно "Данные" впишется ее обозначение.
   Для предварительного выбора цепи программа может расчитать все цепи
в банке. При этом должны быть правильно заданы все значения в окне данных.
Запуск расчета производится нажатием клавиши F5 в банке или в окне данных,
а также из окна "Расчет банка",вызываемого из головного меню.
   Первоначально каждая цепь расчитывается по всем критериям, но в окне
"Расчет банка" их можно установить или отменить нажатием клавиши Enter в
соответсвующей позиции окна. Установленные критерии расчета отмечаются
символом "√".
   Если цепь удовлетворяет всем установленным критериям,то она выделяется
в банке цветом. Если ни одна цепь не удовлетворяет критериям расчета,
перейдите в окно данных и измените их (облегчите условия работы цепи).
   Перейдите в банк и выберите маркером отмеченную цепь наименьшего шага
и рядности,желаемого типа. Если Вы из банка перейдете в другое окно,то в
качестве выбранной будет считаться цепь, на которой перед выходом стоял
маркер банка. Ее обозначение будет вписано в окно данных, а в банке будет
отмечено цветом.                                                         \
?3

@Проверочный расчет цепи
   Если заданы все данные и выбрана цепь, ее можно рассчитать
отдельно по различным критериям из окна данных или банка нажатием
функциональных клавиш F6,F7,F8,F9, а также из окна "Расчет цепи",
вызываемого из головного меню.
   F6-Расчет по геометрической характеристике F(t)2
   F7-Расчет на износостойкость
